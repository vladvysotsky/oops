# oops

> `ghbdtn` → **oops** → `привет`

Утилита для Windows: правит раскладку (RU ↔ EN) и регистр только что набранного
текста по горячей клавише. Работает глобально во всех приложениях.

Названа по тому самому моменту, когда замечаешь, что писал не в той раскладке.

## Как это работает

Программа **не угадывает**, где вы сбились с раскладки. Границу задаёте вы —
повторными нажатиями хоткея область расширяется на слово влево:

```
набрали:   ghjdthrf njuj rfr 'nj hf,jnftn
1-е нажатие →  ghjdthrf njuj rfr 'nj работает      (последнее слово)
2-е нажатие →  проверка того как это работает      (всё набранное)
```

Два шага, а не рост по одному слову: на длинной фразе пословное расширение
потребовало бы нажатий по числу слов. Портится почти всегда либо последнее
слово, либо всё сразу.

Каждый шаг — преобразование **1-в-1** чётко очерченного куска. Корректный текст
за пределами области не трогается. Тот же принцип у хоткея смены регистра:
`мир` → `МИР`, затем вся фраза.

Если следующее нажатие не успело в **окно расширения** (по умолчанию 2 секунды),
начинается новая область — снова с последнего слова.

**Выделенный текст** конвертируется целиком и сразу — границу вы уже задали
выделением, расширять нечего.

Результат печатается напрямую эмуляцией клавиатуры и в буфер обмена никогда не
попадает. Буфер обмена используется только для чтения выделения (другого
универсального способа узнать его в Windows нет) и тут же восстанавливается.

## Возможности

- Правка раскладки и регистра с расширяющейся областью.
- Конвертация выделенного текста целиком.
- Оба хоткея настраиваются. По умолчанию: раскладка — **Ctrl+Win**,
  регистр — **Alt+Win**.
- Глобальный low-level keyboard hook — Visual Studio, браузер, мессенджеры, терминал.
- Сброс набранного на Enter / Tab / Esc / навигации / клике мыши / смене окна /
  ручной смене раскладки / по таймауту.
- Иконка в трее, автозапуск, JSON-настройки в `%AppData%\Oops\settings.json`.

## Обновления

Приложение раз в сутки проверяет [релизы на GitHub](https://github.com/vladvysotsky/oops/releases)
и предлагает поставить новую версию — скачивает инсталлятор и запускает его.
Проверку можно отключить в настройках или запустить вручную из меню в трее.

Релизы собираются автоматически: пуш тега `vX.Y.Z` запускает CI, который
прогоняет тесты, собирает single-file exe и инсталлятор и публикует их.

```powershell
git tag v1.0.0
git push origin v1.0.0
```

## Сборка

Требуется **.NET 8 SDK** на Windows.

```powershell
dotnet build -c Release
dotnet run --project Oops

# Готовый exe одним файлом:
dotnet publish Oops -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Бинарь: `Oops\bin\Release\net8.0-windows\win-x64\publish\oops.exe`

## Тесты

```powershell
dotnet test
```

Покрыто: таблица раскладок, границы слов в буфере, вся арифметика расширяющейся
области (расширение, истечение окна, смена типа хоткея, сохранение длины).

## Сборка инсталлятора

Нужен **.NET 8 SDK** и **Inno Setup 6** (https://jrsoftware.org/isinfo.php).
Скрипт использует синтаксис PowerShell 7 — запускать через `pwsh`:

```powershell
pwsh -ExecutionPolicy Bypass -File installer\build.ps1
```

Готовый `oops-Setup-1.0.0.exe` появится в `dist\`.

## Ограничения

- Только Windows 10/11.
- **Alt+Shift нельзя назначить хоткеем** — это системный шорткат смены раскладки
  Windows, до приложения он не доходит. Окно записи такое сочетание отклоняет.
- В окнах, запущенных от имени администратора (RegEdit, диспетчер задач),
  эмуляция ввода не работает, если само приложение запущено без прав админа.
  Запустите его через «Run as administrator» — но учтите, что тогда перестанет
  работать автозапуск (Windows игнорирует elevated-записи в `HKCU\...\Run`).
- Отладка: low-level hook отключается Windows под отладчиком по таймауту.
  Тестируйте через **Ctrl+F5** или опубликованный exe.
