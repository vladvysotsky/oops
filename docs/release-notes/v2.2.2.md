# oops 2.2.2

## 🔔 О новых версиях программа скажет сама

Раньше обновления проверялись только при запуске программы — а oops живёт в
трее неделями без перезапуска. На деле проверка не шла вообще, и о новой версии
можно было узнать, только нажав «Проверить обновления» самому.

Теперь, пока программа работает, она проверяет обновления **каждые шесть
часов**. Когда выходит новая версия:

- появляется **уведомление Windows** — оно не уводит фокус из того, что вы
  печатаете;
- пункт меню в трее превращается в **«Установить обновление»**, так что
  пропущенное уведомление — не потерянное обновление.

Отключить проверку можно в настройках, как и раньше.

> Эта версия сама до вас дойдёт по-старому — при следующем запуске программы.
> Начиная с неё уведомления будут приходить без перезапуска.

## 🆕 «Что нового» для 2.2.1

У 2.2.1 не было раздела в окне «Что нового», и о её исправлениях — сочетания
больше не отваливаются, замена в выделенном снова работает — было не узнать.
Теперь раздел есть, а у каждого следующего выпуска он будет обязательно.

## ⌨️ Хоткеи по умолчанию

| Действие | Сочетание |
|---|---|
| Раскладка | `Ctrl` + `Win` |
| Регистр | `Alt` + `Win` |
| Перевод | `Ctrl` + `Alt` + `Win` |
| Голосовой ввод | `Ctrl` + `Shift` + `Win` |
| Замена в выделенном | `Alt` + `Shift` + `Win` |
