# oops 2.4.1

## 📋 Список сниппетов по хоткею

Забыли сокращение? **`Ctrl` + `Alt` + `Space`** открывает список сниппетов:

- печатайте — список сужается, искать можно и по сокращению, и по тексту;
- стрелки выбирают, **`Enter`** вставляет сниппет у курсора, **`Esc`**
  закрывает.

Сокращение ищется так же, как при наборе, — по клавишам: «!уу» найдёт «!ee».
Сочетание меняется в настройках, на вкладке хоткеев.

## 🟢 Состояние программы видно в меню

Первый пункт меню в трее показывает точкой, работает ли программа:

- 🟢 зелёная — работает;
- 🟡 жёлтая — на паузе;
- ⚪ серая — выключена.

Клик по пункту включает и выключает программу. «Сниппеты» и «Настройки» теперь
стоят отдельной группой.

## ⌨️ Хоткеи по умолчанию

| Действие | Сочетание |
|---|---|
| Раскладка | `Ctrl` + `Win` |
| Регистр | `Alt` + `Win` |
| Перевод | `Ctrl` + `Alt` + `Win` |
| Голосовой ввод | `Ctrl` + `Shift` + `Win` |
| Замена в выделенном | `Alt` + `Shift` + `Win` |
| Список сниппетов | `Ctrl` + `Alt` + `Space` |
