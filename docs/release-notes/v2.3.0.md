# oops 2.3.0

## ⌨️ Любые две раскладки, а не только русская и английская

Раньше программа знала только пару ЙЦУКЕН ↔ QWERTY, прошитую в коде. Теперь
таблицу для каждой раскладки строит сама Windows, и работает любая, которую вы
добавили в систему: украинская, казахская, немецкая.

**Настройки → «Поведение» → «Первая раскладка» и «Вторая раскладка»** — между
ними и переводит сочетание. По умолчанию это английская и русская. Если
выбранную раскладку потом удалить из Windows, программа сама вернётся к паре по
умолчанию, а добавленную раскладку заметит без перезапуска.

Для русского и английского программа по-прежнему отличает настоящие слова от
набранных не в той раскладке. Для других языков такой проверки пока нет, и
переводится всё, на что вы указали.

## 🔤 Аббревиатуры, единицы и числа больше не портятся

| Набрано | Было | Стало |
|---|---|---|
| `ghbdtn УФНС ltkf` | привет EAYC дела | привет **УФНС** дела |
| `rfr 5 кг ltkf` | rfr 5 ru дела | **как** 5 **кг** дела |
| `5,5кг` | 5?5ru | 5**,**5ru |

Аббревиатуру посреди фразы программа больше не трогает: отличить настоящую
русскую «УФНС» от английской «API», набранной в русской раскладке, по буквам
нельзя. Если нужно перевести английскую аббревиатуру посреди фразы — выделите
её и нажмите сочетание. Если заглавными набрано всё (включённый CapsLock), фраза
переводится как обычно.

## ⏸️ Пауза из трея

Правый клик по значку → **«Приостановить»** → на 15 минут, час или 3 часа.
Программа включится сама — не нужно помнить, что её выключали.

## ⚠️ Предупреждение о другом переключателе

Если рядом работает Punto Switcher, Caramba или похожая программа, oops один раз
скажет об этом. Две программы, перехватывающие клавиатуру, мешают друг другу, и
со стороны это выглядит как «сочетание срабатывает через раз».

## ⌨️ Хоткеи по умолчанию

| Действие | Сочетание |
|---|---|
| Раскладка | `Ctrl` + `Win` |
| Регистр | `Alt` + `Win` |
| Перевод | `Ctrl` + `Alt` + `Win` |
| Голосовой ввод | `Ctrl` + `Shift` + `Win` |
| Замена в выделенном | `Alt` + `Shift` + `Win` |
