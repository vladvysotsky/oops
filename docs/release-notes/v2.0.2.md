# oops 2.0.2

## 🎨 Тема оформления в настройках

На вкладке «Общие» появился переключатель темы: **Авто**, **Светлая**,
**Тёмная**. «Авто» следует за темой Windows и подхватывает её смену **без
перезапуска** — раньше приложение читало тему один раз при старте.

Тема применяется на лету, как и язык; в `settings.json` она попадает только
по «Сохранить».

## 🩹 Починено

- Окно настроек раздувалось при каждом переключении языка или темы: высота
  области вкладок считалась верно только на первом показе, а при пересборке
  разность выходила вдвое больше настоящей — эффект накапливался, и в итоге
  появлялась полоса прокрутки.
- Тёмный заголовок окна оставался тёмным после перехода на светлую тему.
